# Luxuriaegy-

This repository contains a static HTML mockup recreating the provided marketing and brand-building diagrams.

## Files
- `index.html` — main page containing both infographic layouts
- `styles.css` — shared styling and layout setup

## Preview locally
Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
